--------------------
**Topic**: User Feedback on Applications<br>
**Grammar Topic**: Using "should be" followed by present participle to give advice or suggestion.

--------------------

<!--Begin Lesson-->
*Tutor:* 
-We use "should be", followed by a present participle to give advice or suggestions about actions.
-For example: The app should be updated regularly to improve user experience.
-What features do you think an app should have to be successful?

*Student:*
-The app should be memorizing and easy to use.

*Tutor:*
-Good! You use "should be" correctly. Let's refine that a bit. You could say, "The app should be memorable and easy to use."
-Can you think of another feature an app should have?

*Student:*
-The app should let people to work on different methods to achieve the same result.

*Tutor:*
-Nice try! Just a small correction: It should be "let people work on different methods."
-So you could say, "The app should let people work on different methods to achieve the same result."
-Can you give me another example using "should be"?

*Student:*
People should be working right now to improve the app.

*Tutor:*
-Excellent! You used it perfectly. Just a tiny tweak: "We should work more on giving users the right tools."
-Congratulations on your progress today! Now, let's move on to some practice exercises.
